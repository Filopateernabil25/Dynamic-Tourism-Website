#🌍 Dynamic Tourism Website  

## Overview

Dynamic Tourism Website is an educational web project built using PHP and Bootstrap.  
This project was developed as a practical workshop that focuses on building a modern tourism website and converting it from a static layout into a fully dynamic website using PHP fundamentals.

The project emphasizes clean project structure, reusable components, and dynamic content generation.

## Project Objectives

- Built a clean and organized project structure using HTML and Bootstrap
- Designed an attractive and user-friendly interface including
  Navbar, Carousel, Cards, and Footer
- Converted a static website into a dynamic website using PHP
- Used PHP includes to reuse common layout parts
  (Header and Footer)
- Organized all data in a data.php file and applied the
  "Single Source of Truth" concept
- Linked pages using query strings (GET parameters)
  to display city details dynamically
- Used PHP arrays and loops to generate dynamic content

## Features

- Responsive tourism website layout
- Dynamic list of cities and destination details
- Reusable header and footer components
- Clean and simple UI using Bootstrap
- Well-structured and maintainable PHP code
- Beginner-friendly project for students

## Tech Stack

- Backend: PHP
- Frontend: Bootstrap 5
- Styling: Custom CSS + Bootstrap
- Server: Apache (XAMPP)

## Installation

### Prerequisites

- PHP
- Apache Server (XAMPP)

### Steps

1. Clone the repository
2. Move the project folder to the server directory (htdocs)
3. Start Apache server
4. Open the project in your browser using localhost

## Usage

- Browse available tourism destinations
- Click on a city to view its details
- Navigate between pages using dynamic links
- Explore content generated dynamically from PHP data
